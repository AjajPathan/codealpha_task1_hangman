Hangman Game 🎮
📌 Description

Hangman is a simple word-guessing game developed using Python.

The player needs to guess the hidden word by entering letters one at a time. The player has a limited number of attempts. The game is won when the player guesses all the letters correctly before running out of attempts.

🛠️ Technologies Used

Python 3

Random module

Command Line / Terminal

📂 Files
Hangman/
│
├── hangman.py
└── README.md

▶️ How to Run

Make sure Python 3 is installed.

Run the following command in the terminal:

python hangman.py

🎯 How to Play

Start the game.

A random word is selected.

The hidden word is displayed using underscores.

Enter one letter at a time.

If the letter is correct, it is revealed.

If the letter is incorrect, you lose an attempt.

Guess the complete word before all attempts are used.

✨ Features

Random word selection

Interactive gameplay

Tracks guessed letters

Displays word progress

Handles repeated guesses

Limited attempts

Win and lose conditions

🧪 Example
Welcome to Hangman!

Word: _ _ _ _ _

Guess a letter: a

Correct!

Word: _ a _ _ _

Guess a letter: z

Wrong guess!
Attempts remaining: 5

...

Congratulations! You guessed the word!
